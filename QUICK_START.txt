YOUR ACTION RIGHT NOW (3 Steps):
================================================================================

Step 1: Setup Database
----------------------
Windows:
  cd backend\scripts
  START_HERE.bat

Linux/Mac:
  cd backend/scripts
  bash quick_postgres_setup.sh

⏱️ Time: 2 minutes
✅ This sets up PostgreSQL + migrates your data


Step 2: Start Backend
---------------------
  cd backend
  python run.py

⏱️ Time: 5 seconds
✅ Backend runs on http://localhost:8000


Step 3: Verify
--------------
Open these URLs:
  • API Docs: http://localhost:8000/docs
  • Adminer: http://localhost:8080
    Login: postgres / agrisense_user / changeme / agrisense

⏱️ Time: 1 minute
✅ Check your data is there!
