# Assets - Images

Place image assets here (app logo, icons, placeholder images, etc.)

## Recommended Images:

1. **app_logo.png** - App logo for splash screen
2. **placeholder_pest.png** - Placeholder for pest images
3. **placeholder_weather.png** - Placeholder for weather icons
4. **empty_state.png** - Empty state illustration

## Image Guidelines:

- Use PNG format for images with transparency
- Use JPEG format for photos
- Optimize images for mobile (keep file size small)
- Use appropriate resolutions (1x, 2x, 3x for different screen densities)

## Example Usage in Flutter:

```dart
Image.asset('assets/images/app_logo.png')
```
